# Cursor overlay

Applies only in Cursor. Paste this (plus AGENTS.md) into Cursor Settings > Rules > User Rules.

Prefer Cursor for: hands-on editing while I watch, quick local changes, and navigating an unfamiliar file by @-referencing it.
